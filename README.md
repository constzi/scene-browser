# scene-browser

Phone player for previewing exported Bitwig scenes. One static page (`index.html`),
served by GitHub Pages. It contains no personal data: the Google client ID and the
Drive folder are entered on each device and stay in that browser; audio and ratings
are read from the owner's Google Drive after Google sign-in.

Source of truth: the private `hq` repo, `pipelines/bitwig-scenes/scene-browser-web/`.
Copy `index.html` here to publish a new version.
